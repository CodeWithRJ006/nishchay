# Design Plan: "Graduated" Theme

## Core Concept
A professional, legally-binding verification platform with a distinctive "Graduated" aesthetic—inspired by the precision of physical measuring instruments.

## Typography
- **Headings**: Bricolage Grotesque (Bold, robust, high legibility for authoritative data).
- **Interface**: Source Sans 3 (Clean, neutral, highly legible in dense data tables).
- **Technical (Hashes, IDs)**: JetBrains Mono (Unambiguous character differentiation).

## Layout Shells
- **Desktop**: Left-rail navigation grouped by role tasks, with a persistent top bar containing user context and an explicit "Demo Mode" banner.
- **Mobile Field Shell**: Bottom action bar optimized for one-handed use during physical inspections, enforcing a one-task-per-screen flow to minimize cognitive load.

## Motif: The "Tick-Mark"
The UI uses a distinctive ruler "tick-mark" motif (alternating tall and short hash lines) on progress bars, timelines, and decorative borders, reinforcing the "measurement" theme.

## Rejections
Rejected generic SaaS dashboard cards and soft drop-shadows. They feel too playful for a government enforcement platform. We opted for high-contrast, flat borders with architectural precision to convey trust and authority.
