# Nishchay

Nishchay is a legal metrology platform prototype designed to digitize and secure the issuance and verification of weights and measures certificates.

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Initialize database and seed demo data:
   ```bash
   npm run demo:setup
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Check system health:
   ```bash
   npm run preflight
   ```
